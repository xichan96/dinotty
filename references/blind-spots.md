# 审查盲区

## Git 功能变更检查项

1. 检查同一仓库的主工作树和链接 Worktree 是否共享公共目录锁。
2. 检查多命令流程是否在检查与写入之间释放了锁。
3. 检查删除、覆盖、Hard Reset 和 Patch 是否有可见且可恢复的保护措施。
4. 检查备份能否恢复已有文件、目录和原本不存在的路径。
5. 检查路径是否来自服务端重新读取的 Git 状态，并经过工作区边界和符号链接校验。
6. 检查 stdout、stderr、命令日志和 API 响应是否全部执行凭据脱敏。
7. 检查新增后端命令是否同时具备路由、前端入口、中英文文案和行为测试。
8. 检查带 stdin 或自定义环境的 Git 命令是否仍支持日志、取消和仓库互斥。
