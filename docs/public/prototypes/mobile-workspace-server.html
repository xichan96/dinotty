① 工作区：删除与排序修复

现状：≤600px 时纵向列表被隐藏，工作区选择器只有“选择”和“添加”， 删除/重命名/排序完全无入口。

  • 选择器标题栏加 “管理”；进入后搜索框收起，列表变为可拖动。
  • 左侧把手拖动排序；右侧 ✎ 重命名、🗑 删除（带确认）。
  • 默认工作区固定在最上方，只能重命名，不能拖动或删除。
  • 点击“完成”退出管理模式；排序在松手时写回服务端。

② 服务端切换需确认

现状：唯一的入口是底部 24px 状态栏里约 18px 高的服务端小字， 点开后是一个贴着状态栏的小下拉菜单，行高也偏小，手机上很容易点错。

  • 服务端切换改为底部抽屉，与工作区选择器一致。
  • 每行 ≥56px，完整显示名称、地址、状态；当前项有对勾与左侧高亮。
  • 失败的切换留在本页显示原因与“重试”，不关闭抽屉。
  • 状态栏小字的命中区扩到 44px，视觉高度不变。

③ 服务端管理需确认

现状：手机上是“列表 38% 高 + 表单”挤在同一张底部抽屉里； 输入框 13px 会触发 iOS 聚焦缩放，键盘弹出后保存栏容易被遮住， 删除入口埋在表单最底部。

  • 改成列表页 → 编辑页两级。列表每行 58px，点整行进入编辑。
  • 编辑页独立滚动，底部保存栏固定；输入框统一 16px，避免 iOS 缩放。
  • “测试连接”和结果卡片放在地址/Token 之后，删除放在最底部危险区。
  • 返回时若有未保存改动，再弹“放弃修改？”确认。
  • “本机”作为固定行，不可编辑/删除，打消误操作。
需要你确认：编辑页是整页推入（推荐，键盘空间最大）， 还是保留“列表在上、表单在下”的单页结构，只放大触控目标？

④ 服务端排序需确认

现状：手机上隐藏了拖拽把手，只保留“上移 / 下移”两个按钮， 而且必须先点选某一行才能移动。

  • 标题栏增加“排序”，进入后每行左侧出现把手。
  • 按住把手上下拖动，松手即写回顺序；不干扰点按编辑。
  • 上下移动按钮保留，作为无障碍与精确调整入口。
请确认：服务端管理是否采用这个两级结构 + 独立排序模式？ 工作区管理模式是否也按 ① 的方式做？确认后我按原型实现。
