# 工作区管理

工作区（Workspace）是 Dinotty 的顶层隔离单元：每个工作区有独立的 Tab 布局、终端会话、SSH 连接、插件配置。多工作区让你为不同项目（或同一项目的不同任务）建立独立环境。

## 工作区概念

- **隔离**：不同工作区的 Tab、pane、终端会话互不干扰
- **持久化**：工作区状态保存在服务端，重启后恢复
- **多端共享**：所有连接到同一服务端的端看到相同的工作区列表
- **颜色标识**：每个工作区有独立颜色，便于在 Mission Control 中区分

## 创建工作区

| 入口 | 操作 |
|------|------|
| 侧边栏底部 | 点击 `+` 按钮 |
| Mission Control | 概览模式右上角「新建工作区」 |
| Command Palette | `workspace.new` 命令 |

新建时可选：

- **空白工作区**：从零开始配置
- **从模板创建**：套用已保存的布局模板
- **克隆现有工作区**：复制现有工作区的布局（不含会话状态）

## 切换工作区

- **侧边栏**：点击工作区名称
- **Mission Control**：点击工作区缩略图
- **快捷键**：`Cmd + Shift + P` 打开 Command Palette，输入工作区名跳转

切换工作区时，当前工作区的状态保留（不暂停），后台终端会话继续运行。

## 工作区面板

侧边栏的工作区列表显示：

- 工作区名称
- 颜色徽章
- 活动 pane 数量
- 当前连接状态（本地 / SSH）
- 未读通知指示器

右键工作区弹出菜单：

- 重命名
- 修改颜色
- 复制布局为模板
- 删除工作区

## 工作区级插件 Tab

插件 Tab 是工作区级别的：在某个工作区打开的插件只在该工作区可见。这样可以为不同项目配置不同的工具集（如前端项目装 JSON Formatter，后端项目装 DB Browser）。

详见 [插件](../plugins/plugins)。

## 工作区颜色

每个工作区分配一个颜色，取自 One Dark Pro muted 色板：

- 用于侧边栏徽章、Mission Control 缩略图边框、Tab 标题装饰条
- 颜色在创建时自动分配，也可手动修改
- 色板饱和度统一，避免高饱和糖果色

## Mission Control 概览

Mission Control 显示所有工作区的鸟瞰图：

- 工作区缩略图（实时同步 pane 内容）
- 各端连接状态
- 活动 pane 高亮
- 拖拽重排工作区顺序

详见 [多端同步与 Mission Control](multi-device-sync)。
