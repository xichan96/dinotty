1并排优先

主窗口左侧或右侧剩余宽度 ≥ 480px 时，文件浏览器贴边并排、高度对齐主窗口。真正零重叠，两块内容都能完整看到。

2放不下就偏移

两侧都不够宽时，取主窗口尺寸的 95%，相对主窗口偏移 48px 落下，并夹紧到屏幕工作区内。主窗口标题栏和一条边始终露出，不会被完全盖死。

3兜底与尊重用户

主窗口缺失 / 全屏 / 读取失败 → 按工作区 80% 居中，再失败回退 960×640。窗口已存在时只聚焦、不重排尺寸，尊重手动调整。

注：示意图把菜单栏、Dock、窗口装饰都做了约等比例模拟，实际实现只需在创建窗口时计算一次 size/position（内部全用 logical px，读取主窗口的 physical 值后按屏幕 scale factor 换算）。全屏 Space 或 Stage Manager 下系统会强制切换 Space，位置规则不生效，走兜底即可。
