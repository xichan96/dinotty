# 命令收藏

命令收藏（Command Bookmarks）把常用命令保存下来，分组管理，一键执行。比 shell history 更可控，比 shell alias 更直观。

## 收藏命令

### 右键收藏终端文本

在终端 pane 中选中一段命令文本，右键 -> **收藏命令**。命令内容会自动填入新建表单。

### 手动新建

打开命令收藏面板（侧边栏收藏图标），点击右上角 `+` 按钮：

| 字段 | 说明 |
|------|------|
| 名称 | 显示名称（可空，用命令首段） |
| 命令 | 完整命令文本 |
| 分组 | 可选，用于分类（如 `git` / `deploy` / `debug`） |

填好后点击 ✓ 或按 `Cmd + Enter` 保存。

## 分组管理

- **新建分组**：在收藏表单的「分组」字段输入新名称，自动创建
- **切换分组**：面板顶部点击分组标签筛选
- **全部**：显示所有分组的命令
- **拖拽排序**：命令项左侧的 grip 图标拖拽，可跨分组移动

## 一键执行

| 操作 | 行为 |
|------|------|
| 点击命令项 | 把命令发送到当前 pane 的终端（自动回车执行） |
| `Cmd + Click` | 把命令粘贴到终端但不回车（方便编辑后执行） |
| 搜索框选中后回车 | 执行当前高亮项 |
| 搜索框选中后 `Cmd + Enter` | 粘贴不回车 |

::: tip 与广播模式联动
启用 [广播模式](broadcast) 后点击命令，会在所有 pane 同步执行。适合多服务器批量操作。
:::

## 编辑与删除

- **编辑**：右键命令项 -> 编辑
- **删除**：右键 -> 删除，二次确认后删除
- **批量删除**：暂不支持，需逐项删除

## 搜索

面板顶部搜索框支持模糊匹配：

- 匹配名称、命令文本、分组
- `↑` / `↓` 选择，`Enter` 执行
- `Esc` 清空搜索

## 跨工作区共享

命令收藏是**账号级别**的（非工作区级别），所有工作区共享同一份。这样在不同项目里都能用同一套常用命令。

::: tip 配合 SSH
连接 SSH 后点击命令，命令会在远程主机执行。可以为不同远程主机建不同分组，比如 `prod-deploy` / `staging-debug`。
:::
